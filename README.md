# FlowForge

FlowForge is a distributed workflow orchestration and job scheduling engine
built using Java.

## Vision

A reliable platform to define, schedule, execute, monitor, and recover
complex workflows across distributed worker nodes.

## Core capabilities (planned)

- Workflow definitions and versioning
- DAG-based task dependencies
- Priority-based scheduling
- Concurrent task execution
- Distributed worker coordination
- Retry and failure recovery
- At-least-once task delivery
- Observability and monitoring
- AI-powered workflow tasks

## Technology

- Java 21
- Maven
- PostgreSQL
- Apache Kafka
- Redis
- Spring Boot
- Docker
- React

## Modules

- flowforge-common: Shared domain types and utilities
- flowforge-core: Framework-independent workflow engine
